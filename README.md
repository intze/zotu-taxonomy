# zOTU Taxonomy

Ταξινόμηση zOTUs (π.χ. από UNOISE3) σε επίπεδο είδους, με σύγκριση απέναντι σε
ακολουθίες 16S rRNA από **type strains** του NCBI (RefSeq Targeted Loci, bacteria + archaea)
ή, εναλλακτικά, της SILVA 144.
Για κάθε zOTU δίνει τα 5 πιθανότερα είδη με το % ομοιότητας, σε αρχείο Excel.

## Εγκατάσταση (Windows)

1. Από τη σελίδα **Releases** του repository κατέβασε το `ZotuTaxonomy-windows.zip`.
2. Αποσυμπίεσέ το σε έναν φάκελο όπου μπορείς να γράψεις (π.χ. `Documents\ZotuTaxonomy`).
3. Άνοιξε το `ZotuTaxonomy.exe`. Αν τα Windows δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας»,
   πάτα **Περισσότερες πληροφορίες → Εκτέλεση** (το πρόγραμμα δεν έχει ψηφιακή υπογραφή).

Στην πρώτη εκτέλεση κατεβαίνει η επιλεγμένη βάση στον φάκελο `db` (NCBI ~8 MB, SILVA ~400 MB που
γίνονται ~40 MB μετά την επεξεργασία). Χρειάζεται internet μόνο τότε και όταν πατάς «Ενημέρωση βάσης»
(προτείνεται πριν από κάθε νέα ανάλυση, π.χ. ανά εξάμηνο).

## Βάσεις αναφοράς

Διαλέγεις μία βάση ανά εκτέλεση («Βάση αναφοράς» στο παράθυρο, `--db ncbi|silva` στη γραμμή εντολών).

- **NCBI RefSeq (type strains)**, προεπιλογή: η συλλογή 16S rRNA Targeted Loci (~28.000 αλληλουχίες,
  ~21.000 είδη).
- **SILVA 144 (type strains)**: μόνο οι αλληλουχίες της SILVA SSU Ref NR99 που η SILVA σημειώνει ως
  type strain (`[T]` στη στήλη `flags` των metadata). Από τις 32.618 κρατιούνται 27.055 (~16.500 είδη):
  - αφαιρούνται ευκαρυωτικά (1.337) και 16S από χλωροπλάστες/μιτοχόνδρια (191),
  - αφαιρούνται όσες δεν έχουν όνομα είδους (3.866, π.χ. «uncultured bacterium» ή
    «Streptomyces sp. JA03»: συχνά στελέχη που περιγράφηκαν αργότερα ως νέο είδος),
  - αφαιρούνται 169 πιθανώς λάθος σημασμένες: το γένος του ονόματος διαφωνεί με το γένος όπου τις
    τοποθετεί η SILVA, ενώ άλλες αλληλουχίες του ίδιου είδους συμφωνούν.

  Το όνομα είδους είναι το όνομα της αρχικής καταχώρισης (ENA) και μπορεί να είναι παλιό
  (π.χ. *Mycoplasma* αντί *Mycoplasmopsis*). Οι δύο βάσεις συμφωνούν σε ~15.000 είδη· κάθε μία έχει και
  είδη που λείπουν από την άλλη (μέρος της διαφοράς είναι απλώς διαφορετική ονοματολογία).

## Χρήση

1. **Επιλογή…** → διάλεξε το FASTA με τα zOTUs.
2. Πάτα **Εκτέλεση**. Για ~3.300 zOTUs η αναζήτηση κρατά περίπου 10 λεπτά σε 4 πυρήνες.
3. **Άνοιγμα Excel** όταν τελειώσει.

Το `example_zotus.fasta` (5 γνωστά βακτήρια) είναι για γρήγορη δοκιμή.

## Τι περιέχει το Excel

| Φύλλο | Περιεχόμενο |
|---|---|
| Summary | Μία γραμμή ανά zOTU: καλύτερη ομοιότητα, κατάσταση, είδος/γένος, τα 5 πρώτα είδη με % και accession |
| Top hits | Τα ίδια σε «μακριά» μορφή (μία γραμμή ανά zOTU × είδος) |
| Settings | Βάση, ημερομηνία λήψης, όρια, κόψιμο primer — για την ενότητα Μεθόδων |

**Κατάσταση (Status):**

- **Species**: ένα μόνο είδος στην καλύτερη ομοιότητα, ≥ όριο είδους (98,65%).
- **Ambiguous: N species tied**: πολλά είδη με την ίδια καλύτερη ομοιότητα. Η περιοχή του 16S δεν τα ξεχωρίζει.
- **Genus level only**: ομοιότητα μεταξύ ορίου γένους (94,5%) και ορίου είδους.
- **Below genus threshold**: ομοιότητα 80–94,5%. Πιθανώς νέο ή ακαλλιέργητο taxon.
- **No type strain >= min identity**: κανένα περιγεγραμμένο είδος πάνω από 80%.

## Ρυθμίσεις

- **Είδη ανά zOTU**: πόσα είδη θα εμφανίζονται (προεπιλογή 5).
- **Όριο είδους / γένους**: 98,65% και 94,5% (Kim et al. 2014; Yarza et al. 2014).
  Τα όρια έχουν οριστεί για το **πλήρες** 16S, οπότε για αμπλικόνια ~400 bp είναι ενδεικτικά.
- **Ανοχή ισοπαλίας**: είδη μέσα σε αυτή τη διαφορά (%) από το καλύτερο μετρούν ως ισοπαλία.
  Με 0 μετρούν μόνο οι ακριβώς ίσες τιμές. Για ~420 bp, 1 βάση ≈ 0,24%.
- **Ελάχ. κάλυψη zOTU** (`--min-cov`, ίδιο με `--query_cov` του vsearch): τι κλάσμα (0–1) του
  zOTU πρέπει να στοιχιστεί στην αναφορά (προεπιλογή 0,9). Τα gaps δεν μετράνε, άρα πολύ υψηλή
  τιμή (π.χ. 0,99 ≈ 4 βάσεις στα 430 bp) απορρίπτει και hits με μικρές εισαγωγές.
- **Αυτόματο κόψιμο primer**: αφαιρεί υπολείμματα των primers 341F/805R που έχουν
  εκφυλισμένες θέσεις (W) και θα έδιναν ψεύτικη διαφορά μιας βάσης.

## Μέθοδος (για δημοσίευση)

Global alignment με vsearch v2.30.0 (`--usearch_global`, ταυτότητα χωρίς τα ακραία κενά, και οι δύο κλώνοι,
`--query_cov 0.9`, `--maxaccepts 200 --maxrejects 2000`) απέναντι στη συλλογή NCBI RefSeq 16S rRNA Targeted Loci
(ή στα type strains της SILVA 144 SSU Ref NR99, όπως περιγράφεται παραπάνω).
Για κάθε zOTU κρατιέται η καλύτερη ομοιότητα ανά είδος και τα είδη ταξινομούνται κατά % ομοιότητας.
Σε δοκιμή 150 τυχαίων zOTUs, η ευρετική αναζήτηση έδωσε ίδια αποτελέσματα με την εξαντλητική για όλες τις
ομοιότητες ≥ 94,5%.

```
python zotu_taxonomy.py --help
python zotu_gui.py
```
